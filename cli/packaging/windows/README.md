# Vogo

## Create a desktop shortcut:
1. open powershell
2. copy and paste this without the quotes: 'powershell -NoExit -ExecutionPolicy Bypass -File'
3. in file explorer, right click the 'create-shortcut' file and click Copy as Path
4. paste into powershell that path. Click enter. 

## Misc:
- you can place this folder (extracted from the zip file) wherever you'd like, but I recommend the downloads folder. This is because when you download a new version you can easily extract the new one and replace the old one. Your configuration file (storing your username and password) is kept in another location, by default its in %APPDATA%\vogo. This is the only file that shouldn't be moved around or deleted.
